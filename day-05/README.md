# Day 5 — JavaScript Employee Dashboard

## Objective
Learn modern JavaScript, asynchronous programming, and APIs.

## Practical Assignment
Build a JavaScript Employee Dashboard that supports:
- List employees
- Search employees
- Filter employees
- Sort employees
- View employee details
- Add employee
- Edit employee
- Delete employee

## Technology
- HTML
- CSS
- Modern JavaScript (ES6+)
- JSON
- Fetch API

## How to Run
Open `employee-dashboard/index.html` in a browser.

For the Fetch API/JSON version, it is recommended to run the folder with VS Code Live Server.
